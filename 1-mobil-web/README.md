# 📱 1. Aşama: Mobil Web & PWA Uygulaması

Bu klasör, projenin **tek dosya halinde çalışan, internetsiz ve sıfır kurulumlu mobil web versiyonunu** içerir.

## 📄 Dosyalar
- **`GlukoDenge-Mobil.html`**: Uygulamanın tüm arayüz, stil, ikon ve JavaScript mantığını tek bir dosyada barındıran çekirdek uygulama.
- **`gizlilik-politikasi.html`**: Kullanıcı veri güvenliği ve Google Play Store için hazırlanmış resmi gizlilik politikası.

## 🌟 Özellikler
- Hiçbir sunucu veya internet bağlantısı gerektirmez.
- `localStorage` teknolojisi ile verileri kullanıcının telefonunda saklar.
- Mobil tarayıcılardan (Chrome, Safari, Samsung Internet) **"Ana Ekrana Ekle"** denildiğinde tıpkı yerel bir mobil uygulama gibi tam ekran çalışır.
