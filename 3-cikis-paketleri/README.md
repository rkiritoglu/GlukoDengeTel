# 📦 3. Aşama: Hazır Dağıtım ve Yükleme Paketleri

Bu klasör, doğrudan kullanıma veya mağaza dağıtımına hazır son ürün paketlerini barındırır.

## 📱 Paketler
1. **`GlukoDenge-v1.0.0.apk`** (Boyut: ~3.49 MB)
   - **Kullanım Amacı:** Android telefonlara doğrudan USB kablo, WhatsApp, Drive veya tarayıcı üzerinden yükleme (sideloading).
   - **Gereksinim:** Android 7.0 (Nougat / API 24) veya daha yeni bir Android sürümü.
   - **Yükleme:** Dosyayı telefonda açıp `Yükle` butonuna basmanız yeterlidir.

2. **`GlukoDenge-v1.0.0-PlayStore.aab`** (Boyut: ~3.35 MB)
   - **Kullanım Amacı:** Google Play Console mağaza yayını için optimize edilmiş resmi Android App Bundle formatı.
   - **Avantajı:** Google Play, kullanıcının cihaz mimarisine göre yalnızca gerekli parçaları indirerek paket boyutunu optimize eder.
