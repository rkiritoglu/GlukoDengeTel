# 📜 4. Aşama: Projenin Tarihçesi ve Erken Sürümleri

Bu klasör, GlukoDenge projesinin başlangıçtan bugüne nasıl adım adım geliştirildiğini gösteren tarihsel arşiv dosyalarını içerir.

## 📁 Alt Dizinler
- **`web-prototip/`**: Projenin ilk masaüstü web prototipi (`Seker`).
- **`veri-tabanlari/`**: İlk aşamalarda test edilen yerel metin tabanlı veritabanı denemeleri (`Web`).
- **`ilk-taslaklar/`**: Erken dönem HTML arayüz taslakları (`SekerTakip2`, `SekerTakip3`, `Şeker Takip ve Analiz Paneli1`, diyet listeleri).

Bu arşiv, projenin tek bir HTML sayfasından modern ve tam teşekküllü bir Android mobil sağlık uygulamasına evrilişini belgeler.
